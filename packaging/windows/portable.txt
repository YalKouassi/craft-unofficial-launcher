Craft Unofficial Launcher portable mode

While this file sits next to craft-unofficial-launcher.exe, Craft Unofficial Launcher keeps its settings, its
download cache and its record of installed apps in the CraftUnofficialLauncherData folder beside it, and
writes nothing to %APPDATA%. Copy the whole folder to move Craft Unofficial Launcher with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Craft Unofficial Launcher) instead.
If CraftUnofficialLauncherData can't be written (for example on a read-only drive), Craft Unofficial Launcher says
so and uses %APPDATA%\Craft Unofficial Launcher instead.
